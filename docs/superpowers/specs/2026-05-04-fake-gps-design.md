# 高級擬真 Fake GPS App 設計規格書 (Android)

## 1. 專案概述
開發一個具備「高擬真行為模式」的 Android 模擬位置應用程式，專為需要規避行為大數據偵測的遊戲（如皮克敏、寶可夢）設計。

## 2. 核心功能
### 2.1 混合移動模式
- **虛擬搖桿 (Joystick)**：懸浮於螢幕上，支援 360 度方向控制。
- **路徑導航 (Route Navigation)**：在地圖上點選多個路徑點，App 自動規劃道路路徑並行走。

### 2.2 速度與運動邏輯
- **目標速度**：強制維持在 **15 ~ 20 km/h** 區間。
- **運動演算法**：
    - **轉彎自動減速**：當路徑轉向角度大於 45 度時，速度自動降至 10 km/h 以下，完成轉彎後恢復。
    - **加速度曲線**：起步與停止具備平滑加減速效果（Easing）。
    - **隨機速度抖動**：在 15-20km/h 之間每秒產生微小波動，避免恆定速度。

### 2.3 高擬真防偵測特徵 (Behavioral Anti-Detection)
- **座標隨機漂移 (Gaussian Jitter)**：座標輸出時疊加 0.5~1.5 公尺的隨機擾動，模擬真實 GPS 訊號誤差。
- **隨機停頓 (Micro-Stops)**：長途移動中隨機停等 5~30 秒（模擬等紅綠燈）。
- **海拔同步 (Altitude Simulation)**：獲取真實地表高度並同步至 Location 物件。

## 3. 技術架構
- **開發平台**：Android (Kotlin/Java)。
- **系統介面**：使用 `Android Mock Location API`。
- **地圖整合**：Google Maps SDK 或 Mapbox 用於路徑規劃與顯示。
- **環境相容性**：設計目標為 Android 無 Root 環境，建議搭配虛擬容器（如 VMOS/VPhoneGAGA）使用以隱藏標籤。

## 4. 成功標準
1. App 能穩定輸出座標至系統。
2. 在地圖測試工具中觀察到座標具備擬真抖動與平滑轉彎。
3. 速度嚴格控制在 20km/h 以下。
